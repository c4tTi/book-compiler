# Glossary

| Term | Meaning |
|---|---|
| **AC-coupled** | Battery with its own inverter, connected on the house's AC side. Works with any existing PV inverter. |
| **Autarky (Autarkiegrad)** | Share of your *consumption* covered by your own PV. |
| **BFE** | Bundesamt für Energie, the Swiss Federal Office of Energy. |
| **DC-coupled / hybrid inverter** | PV and battery share one inverter. Fewer conversions, so more efficient. |
| **DoD** | Depth of discharge: how much of the capacity is used per cycle. |
| **EIV / KEV** | One-off investment grant / former cost-covering feed-in tariff (2009-). |
| **ElCom** | Federal Electricity Commission, which publishes tariffs. |
| **EMS** | Energy management system: controls battery, heat pump, EV and boiler (e.g. Solar Manager). |
| **Ersatzstrom / Notstrom** | Whole-house backup / single emergency socket during a blackout. |
| **HKN** | Herkunftsnachweis, a guarantee of origin. Some utilities pay extra for it. |
| **LEG** | Lokale Elektrizitätsgemeinschaft, a local electricity community (from 2026). |
| **LFP / NMC** | Lithium-iron-phosphate (safer, longer life) / nickel-manganese-cobalt chemistries. |
| **Mindestvergütung** | Legal minimum feed-in payment since 2026 (6 Rp/kWh ≤ 30 kW). |
| **Referenz-Marktpreis** | BFE quarterly PV market price that sets harmonised feed-in pay. |
| **Rp** | Rappen (1/100 CHF). |
| **Self-consumption (Eigenverbrauch)** | Share of your *production* used on site. |
| **SG-Ready** | Heat-pump interface that lets it run harder on PV surplus. |
| **SPI** | System Performance Index (HTW Berlin): overall efficiency of PV-battery system, incl. standby. |
| **Usable capacity** | kWh you can actually use (quotes sometimes give nominal kWh). |
| **V2H / V2G** | Vehicle-to-home / vehicle-to-grid bidirectional charging. |
| **VKF** | Association of cantonal fire insurers, which issues fire-protection rules. |
| **VNB** | Verteilnetzbetreiber, your local grid operator/utility. |
| **ZEV / vZEV** | (Virtual) self-consumption community of neighbouring buildings. |
