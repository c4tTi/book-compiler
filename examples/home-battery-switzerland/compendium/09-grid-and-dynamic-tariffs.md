# 09 · Dynamic tariffs, the grid, and future-proofing

## 9.1 Where extra value could come from

- **Dynamic tariffs** (EKZ optional from 2026, Groupe E VARIO) let a battery charge at cheap
  hours, including from the grid in winter, and discharge at peaks. They need a smart meter + EMS
  [@ekz2025dyn; @groupee-vario; @solarmanager-dyn]. HTW calculates that grid charging for arbitrage only pays with ≥ 71 %
  system efficiency, which not all systems reach [@htw2026inspektion]. Nordic research finds that scheduling
  strategy and wear costs decide whether arbitrage pays [@karttunen2026nordic]. ⚠️ Swissolar calls arbitrage
  "not yet really attractive" in Switzerland [@swissolar2026bm].
- **Pooling / virtual power plants** and grid-serving incentives are announced but still
  mostly aimed at commercial systems [@swissolar2026bm].
- **Grid-fee refund** for stored-and-reinjected power (2026) [@swissolar2026neu].

## 9.2 The system critique

- US metered data: batteries run only for self-consumption deliver **virtually zero value to the
  grid**. Allowing discharge in peak hours would recover 50-80 % of the potential
  [@forrester2022grid]. European work similarly finds system contributions depend on the operating mode [@yu2021system].
- BFE-commissioned study: home batteries are privately rational but systemically less efficient than
  large batteries and thermal storage, and they shift grid costs to others [@energeiaplus2026speicher; @schlecht2025speicherbedarf].
- Swissolar counters that batteries let more PV connect without grid expansion, and it calls for a national storage
  strategy [@srf2026bm; @swissolar2026bm; @forumspeicher2023]. Online tech communities argue the opposite, that rooftop solar + home batteries make a clean grid cheaper [@hn2021volts].

## 9.3 What this means for you

- 🔎 **Tariff risk:** if utilities shift toward power-based or fixed grid charges (which the system
  critique argues for), the per-kWh saving of a battery falls. If dynamic tariffs spread, it rises.
  Nobody can tell yet which way it goes.
- Future-proofing: choose a system with an **open EMS interface** (Modbus/SunSpec, listed as
  "active control" in Solar Manager or similar) so it can follow future tariffs [@solarmanager-dyn].

## Purpose note

This is optional for the buy/no-buy decision, but essential for choosing *which* system: buy controllable,
not a closed box.
