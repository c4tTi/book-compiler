# Site check for your balcony or roof

Fill in before you buy anything. A "no" in a **must** row means stop or choose an off-site location (compendium ch. 3). Sources: [@bgd49; @bsnachbarn; @honigmacherdach; @imkerforumbalkon; @gech].

| # | Question | Must / should | Yes / No / Notes |
|---|---|---|---|
| 1 | Written consent from landlord/owner covering location, number of hives, access? | must | |
| 2 | Site on private (not city-owned) property? If it is a city-owned building, city approval? | must | |
| 3 | Nobody in household or immediate neighbours with known bee-venom allergy (or they're informed and equipped)? | must | |
