# Scope: Sourdough Bread Baking

- **Request:** compile everything you can find about sourdough bread baking, i want to write a beginners guide book from it
- **Purpose:** Material for writing a beginner's guide book on sourdough bread baking
- **Audience:** Home bakers with no sourdough experience (the book's readers); the user (author) needs both practical method and the science/history behind it to explain the 'why'.
- **Depth:** Beginner-to-intermediate practice, backed by the actual science; enough depth that the author can explain and fact-check, not a research monograph.
- **Languages / regions:** Mainly English; sample French (levain), German (Sauerteig), Italian (lievito madre) and other traditions (rye, San Francisco, Scandinavian, Eastern European) for the cultural lens.
- **Out of scope:** Commercial-scale bakery engineering in detail; sourdough non-bread products (pancakes, crackers) only briefly; yeasted/commercial-yeast bread except for comparison. Defaults chosen without asking (user away).
- **Started:** 2026-09-28

This file is a working document: edit or rewrite any part of it freely.
